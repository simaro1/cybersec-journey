## What I learned

* Virtualization allows for apps and devices to be virtualized raather than physical Many benefits to this such as cost saving
better resource usage, flexibility, portability, scalability etc.
* What hypervisor's are, essentially a monitor of each computer and turning them into virtual ones, allocates CPU, memory and storage
allows for safe isolation and you can use it to manage lifecycle of lab machines.
* Lab machines, which are virtual computers created by hypervisor. Runs any OS and  isolated
* And containers which runs a single app and all the components to support it. Borrows core of existing system, but rely on the same OS as host
